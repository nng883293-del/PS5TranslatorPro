# PS5 Translator Pro — تطبيق أندرويد أصلي (APK)

## 1) خطوات بناء ملف الـ APK في Android Studio
1. فك الضغط عن مجلد `PS5TranslatorPro`.
2. افتح برنامج **Android Studio** على الكمبيوتر واضغط **Open** واختر مجلد `PS5TranslatorPro`.
3. انتظر 1-2 دقيقة حتى ينزل Gradle المكتبات (`ML Kit` و `OkHttp`).
4. من القائمة العلوية اختر:
   `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`
5. ستجد ملف `app-debug.apk` داخل:
   `app/build/outputs/apk/debug/app-debug.apk`
6. انقل ملف الـ APK لتلفونك وثبته!

## 2) الحصول على مفتاح Gemini API مجاناً (30 ثانية)
1. ادخل على: https://aistudio.google.com/app/apikey
2. سجل بحساب قوقل واضغط **Create API Key**.
3. انسخ المفتاح ولصقه بالتطبيق واضغط **اختبار سرعة الترجمة والقارئ الصوتي**.

## 3) أفضل طريقة للعب مع البلي 5
- استخدم تطبيق **Chiaki-ng** (مجاني ومفتوح المصدر للـ PS5 Remote Play على أندرويد) أو **PXPlay** أو **PS Remote Play**.
- داخل لعبة GTA 6 فعّل **Subtitle Background** (الخلفية السوداء للترجمة) حتى يقرأ الـ OCR بدقة 100%.
- شغّل `PS5 Translator Pro`، اضغط **تشغيل المترجم العائم**، اسحب المربع الأخضر على سطر الترجمة باللعبة، واضغط **تأكيد ✓**.
- للتبديل بين **الفصحى الأصلية** و**اللهجة العراقية** أو تشغيل/كتم **القارئ الصوتي**، اضغط الأزرار السريعة مباشرة فوق الشريط العائم بدون ما تطلع من اللعبة!
